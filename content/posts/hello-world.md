Welcome to my blog! This is my first post using Hugo.

## What is Hugo?

Hugo is a fast static site generator written in Go. It's designed to make building websites fun again.

## Getting Started

To create a new post, run:

```bash
hugo new posts/my-new-post.md
```

Then edit the file and set `draft = false` when ready to publish.
